## Key Concepts
Hash table is an effective data structure for that can store key value as an index with a value. This enables O(1) averege time complexity for the basic operations such as seacrching, inserting, and deleting. The problem is that it could take the worst time complexity case of O(n) for every operation when the load factor gets bigger, which how many elements are there compared to the size of the hash table, and when the elements are not evenly distributed.
